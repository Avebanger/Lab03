# Домашнее задание к работе 3

## Условие задачи
Написать и отладить программу определения силы притяжения между двумя телами с задаваемыми массами и заданном расстоянием между ними.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Объявить константы:
   - `G` = 6.67e-11  — гравитационная постоянная.
3. Задать исходные данные:
   - `m1` — масса первого тела (кг).
   - `m2` — масса второго тела (кг).
   - `r`  — расстояние между телами (метры).
4. Вычислить силу притяжения между телами:
   - `F` = `G` * `m1` * `m2` / (`r` * `r`)
5. Вывести результаты расчетов с подстановкой всех значений в текст.
6. **Конец**

## 2. Реализация программы
```
#include <stdio.h>
#include <locale.h>
#define G 6.67e-11
// Закон всемир тяготения: F = G * m1 * m2 / (r * r);
int main()
{
	setlocale(LC_CTYPE,"RUS");
	double F,m1,m2,r;
	printf("Введите массу первого тела в кг: ");
	scanf("%lf",&m1);
	printf("Введите массу второго тела в кг: ");
	scanf("%lf", &m2);
	printf("Введите расстояние между телами в метрах: ");
	scanf("%lf", &r);
	F = G * m1 * m2 / (r * r);
	printf("Сила притяжения между телами в Ньютонах: %.4f", F);
}
```
